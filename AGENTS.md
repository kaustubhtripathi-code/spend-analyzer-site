# AGENTS.md — spend-analyzer-site

Public static landing page for Spend Analyzer (the owner's local-first, AI expense app; source in the
separate private `spend-analyzer` repo, page source mirrored at `marketing/website/` there). Served by
GitHub Pages at https://kaustubhtripathi-code.github.io/spend-analyzer-site/. Status: live, rarely changed.

## Stack & layout
- Single `index.html` (inline CSS/JS), `assets/` (screenshots + demo mp4), `.nojekyll`.
- `ci/site_check.py` — offline link/JS check that stages tracked public assets into `_site/`.
- `.github/workflows/ci-cd.yml` — runs the check; on `main` pushes, deploys `_site/` to GitHub Pages.

## Setup
None (no dependencies; Python 3 + Node 22 used by the check).

## Run / build / test / lint
```bash
python ci/site_check.py --repo spend-analyzer-site   # (verified 2026-10-11) creates _site/ — delete it afterwards (not gitignored)
python -m http.server 8000                           # local preview (unverified)
```

## Rules for agents
- **Merging/pushing to `main` deploys the public site.** Work on a branch; the owner merges.

- Keep all referenced assets relative and tracked; `site_check.py` fails on missing references or symlinks.
- Do not commit `_site/`.
